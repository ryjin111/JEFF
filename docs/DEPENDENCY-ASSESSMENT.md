# Restricted text-pilot dependency assessment

Assessed 9 October 2026. The pinned OpenClaw `2026.9.9` tree contains npm `11.20.0` and **five affected bundled package entries: three high and two moderate**. Several entries group multiple advisories. They remain installed and unresolved; this assessment does not establish a clean dependency tree.

**Release decision:** retain only the restricted text pilot with external tools and package-management actions denied. Broad launch and additional runtime tools remain blocked until a reviewed fix is verified against the final artifact, or the operator explicitly accepts the named residual risks and records the scope, controls and review date. This assessment does not complete holder, monitoring, recovery or production acceptance gates.

JEFF configures OpenClaw with `tools.profile=minimal` and `deny=["*"]`, passes holder text to a fixed local agent command, and supplies a restricted child environment. Private responses use `Cache-Control: no-store`; JEFF does not use npm's shared cache to serve holder responses. These controls reduce the intended text workflow's exposure. They do not remove the packages or establish that every dependency path is unreachable.

Two actual installed-CLI fixture turns, covering NFT and standalone-account scopes, completed on Windows with test-only hooks denying npm module loads and detected npm/npx launches. Neither turn attempted those operations. Positive controls exercised all five affected modules and two npm subprocess cases. This is finite successful-path evidence, not an operating-system sandbox or a security proof. CLI startup still invokes platform probes. Linux behavior, error/background/update paths, package management and adversarial provider WebSocket behavior were not established by these fixtures. New releases and enabled capabilities require reassessment.

No supported clean replacement was demonstrated. Nested overrides left the bundled versions unchanged. Read-only inspection of the official [npm 11.21.0](https://registry.npmjs.org/npm/11.21.0) and [npm 12.2.0](https://registry.npmjs.org/npm/12.2.0) tarballs found the same five bundled versions. The current [OpenClaw registry artifact](https://registry.npmjs.org/openclaw/2026.9.9) still selects npm `11.20.0`. npm documents [bundled dependencies and overrides](https://docs.npmjs.com/cli/v11/configuring-npm/package-json/); a registry `fixAvailable` flag alone does not prove a repaired installed bundle.

The separate component fixture reported a clean audit, but it was not the JEFF/OpenClaw tree and was not shipped. In particular, its `http-cache-semantics@4.3.0` candidate lies outside the recorded vulnerable range, while the [reviewed advisory](https://github.com/advisories/GHSA-ch52-4w7c-c8xp) currently lists **no patched version**. Do not describe 4.3.0 as an advisory-confirmed fix. A reproducible vendor repair needs source review, compatibility checks, a fresh installed-artifact audit and runtime verification before release.

Local evidence is retained under `evidence/release/`: `dependency-assessment-20261009.json`, `dependency-recheck-20261009.json`, `dependency-nested-overrides-audit.json`, `dependency-patched-components-audit.json` and `dependency-reachability-20261009.json`. The reachability record covers source `2ff9a919006a8ade4c95fe45fe1f984fdbae8b3a`; it does not silently extend to every later candidate or production path.
