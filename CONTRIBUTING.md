# Contributing

Contributions are welcome when they preserve JEFF's typed contract, reproducibility, and shadow-only safety boundary.

1. Create a focused branch.
2. Add or update tests for behavioral changes.
3. Run `npm run verify`.
4. Document any benchmark or artifact changes.
5. Open a pull request with the exact scope and verification output.

Do not tune on sealed labels and then report the same set as independent evidence. New benchmark claims require frozen stimuli, predictions fixed before labels, independent labeling, and hash-bound receipts.
